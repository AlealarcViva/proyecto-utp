# Vacantes UTP

Sitio web para consultar y buscar vacantes relacionadas con una universidad. El proyecto está publicado mediante Firebase Hosting.

- **Sitio web:** https://vacantes-utp.web.app
- **Tecnologías confirmadas:** HTML y Firebase Hosting.
- **Funciones documentadas:** consulta y búsqueda de vacantes.

> **Nota:** Firebase Hosting publica los archivos del sitio. Esta configuración, por sí sola, no significa que el proyecto tenga una base de datos, autenticación de usuarios o un panel de administración.

## Funcionalidades actuales

- Consultar la información de vacantes que muestra la página.
- Buscar vacantes mediante las opciones de búsqueda disponibles en la interfaz.

El comportamiento exacto de la búsqueda depende de cómo esté implementado en el código. Este README no presupone filtros, inicio de sesión, formularios, almacenamiento de datos ni otras funciones no confirmadas.

## Acceso al sitio

Visita: https://vacantes-utp.web.app

Abre la página en un navegador actualizado. Para utilizar la búsqueda, escribe el término en el campo correspondiente si está disponible y sigue los controles que aparecen en la página.
